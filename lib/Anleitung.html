YAML File Creation Guide

This guide explains how to create YAML files for the CommandGeneratorPage in a Flutter application. These YAML files define the structure, parameters, and behaviors of commands.

1. Basic Structure

Each YAML file consists of the following main elements:

  • command: The name of the command (e.g., nmap, mkdir).
  • description: A short description of the command.
  • parameters: A list of parameters supported by the command.
command: nmap
description: Network mapping and port scanning tool
parameters:
  - name: target
    type: text
    required: true
    description: Target host(s) or network(s) to scan
    example: "192.168.1.1"
    order: 1

2. Field Definitions

command

Description: The main command to execute.

command: mkdir

description

Description: A short explanation of the command.

description: Create directories

parameters

Description: A list of parameters that define the command’s behavior.

Parameter Fields

  • name: The internal name of the parameter.
  • type: Defines the parameter type. Possible values:
    • text: Free text input.
    • boolean: A toggle (true/false).
    • options: A selection from predefined options.
    • filepath: A file or directory picker.
  • flag: The flag to add before the value in the command.
  • description: A short explanation of the parameter.
  • required: Indicates if the parameter is mandatory.
  • order: Specifies the order of the parameter in the command. Use 0 to place it before the command.
  • prefix and suffix: Optional; text to add before or after the parameter value.
  • options: A list of predefined values (for type: options).
  • example: An example value for the parameter.

3. Example YAML File

command: mkdir
description: Create directories
parameters:
  - name: use_sudo
    type: boolean
    flag: "sudo"
    description: Run the command with elevated privileges
    default: false
    order: 0

  - name: path
    type: filepath
    mode: directory
    required: true
    description: Path where the directory will be created
    example: "/home/user/newdirectory"
    order: 1

  - name: parents
    type: boolean
    flag: "-p"
    description: Create parent directories if they don’t exist
    default: false
    order: 2

  - name: verbose
    type: boolean
    flag: "-v"
    description: Print information about created directories
    default: false
    order: 3

4. Tips for Creating YAML Files

  • Indentation: YAML is indentation-sensitive. Use 2 spaces for each level.
  • Order: Use the order field to control the order of parameters.
  • Testing: Test the YAML file in the CommandGeneratorPage to ensure it behaves as expected.

5. Example Command Output

Using the example YAML configuration, the generated command could look like this:

sudo mkdir -p -v /home/user/newdirectory
